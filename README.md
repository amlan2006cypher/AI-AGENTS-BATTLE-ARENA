# AI Agent Battle — Tic-Tac-Toe

## Assignment X_02 — AI/ML Laboratory

This project implements two decision-making AI agents that compete in Tic-Tac-Toe. The objective is not merely to create a game, but to experimentally study how search depth and heuristic design affect AI decisions and computational cost.

## Requirements Implemented

- Python-based Tic-Tac-Toe engine
- Minimax search
- Alpha-Beta pruning
- Configurable search depth
- Heuristic evaluation functions
- Two named AI agents
- Automatic AI-vs-AI matches
- Search-depth experiment
- 10-game agent battle
- Node, pruning and execution-time statistics
- CSV result storage
- OOP-based organization

## Agents

### NEXUS
- Algorithm: Minimax + Alpha-Beta pruning
- Search depth: 3
- Heuristic: H1
- Strategy emphasis: immediate threats, blocking, center control and corners.

### TITAN
- Algorithm: Minimax + Alpha-Beta pruning
- Search depth: 3
- Heuristic: H2
- Strategy emphasis: weighted potential winning lines, center/corner control and positional control.

Both agents use the same search algorithm and are intentionally competent. Their main difference is how they evaluate non-terminal positions.

## Heuristics

### H1 — Threat-Focused
H1 strongly rewards two-in-a-row opportunities and penalizes opponent threats, while also considering center and corner control.

### H2 — Position-Focused
H2 evaluates potential winning lines with different weights and gives stronger positional weights to the center and corners, with a small edge preference.

## Search Depth Experiment

The experiment fixes the algorithm and heuristic and varies depth across:

- Depth 1
- Depth 2
- Depth 3
- Depth 4

For each depth, 10 games are run and the program records evaluated nodes, pruned nodes and execution time.

## Agent Battle

NEXUS and TITAN play 10 games at depth 3. The starting player alternates between the agents to reduce first-player bias.

## Running the Project

Requires Python 3.9+.

Run both experiments:

```bash
python main.py
```

Run only the depth experiment:

```bash
python main.py --mode depth
```

Run only the 10-game battle:

```bash
python main.py --mode battle
```

The generated CSV files are stored in `results/`.

## Important Experimental Principle

The game results are generated by the program and saved to CSV. They should not be manually hard-coded. The report interprets the observed evidence rather than assuming that one agent must win.
